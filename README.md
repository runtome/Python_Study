## How to study

1. Open a lesson and read the comments from top to bottom.
2. Run it: `python lessons/02_lists_and_matrix.py` and compare the output with what you expected.
3. Change values and re-run. Breaking things is a good way to learn!
4. Do the **TRY IT YOURSELF** exercises at the bottom of each lesson.
5. Check your answers: `python lessons/solutions.py`

Requires Python 3.10 or newer (lesson 05 uses `match`).
